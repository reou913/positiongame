# 薩摩川内じんとりマップ

今いる場所に1日3つ点を打って、3つの点で囲んだ三角形を自分の陣地にする陣取りゲームです。歩いて場所を変えながら遊びます。
地図は Leaflet（OpenStreetMap）、データとログインは Supabase を使います。

## 遊び方

- 「今いる場所に打つ」を押すと、スマホの位置情報で今いる場所に点を打てます。地図を押しても打てません
- 1日に3つまで打てます（日本時間の0時に戻ります）
- 3つそろうと、その三角形が自分の色で半透明に塗られます
- ほかの人の陣地と重なったところは、後から三角形を作った人のものになります
- 同じ日の点どうしは100m以上はなれて、3km以内にします（同じ場所で3回打てないように・大きすぎる三角形を防ぐため）
- 位置の誤差が100mより大きいときは打てません（空が見える場所で待つと、正確になります）
- 三角形になる前なら「1つ戻す」で取り消せます
- 「ランキング」で、今の陣地の広さを比べられます
- 左上の名前を押すと、ニックネームを変えられます。色は自動で決まります

## しくみ

| 部分 | 使っているもの | 役割 |
| --- | --- | --- |
| 地図 | Leaflet ＋ OpenStreetMap | 地図の表示、点や三角形を描く |
| 陣地の計算 | Turf.js | 重なりを削る計算、広さの計算 |
| ログイン | Supabase の匿名ログイン | メールもパスワードもなしで、ブラウザごとにプレイヤーを作る |
| データ | Supabase の profiles・points テーブル | プレイヤーの色と名前、打った点 |
| 現在地 | ブラウザの位置情報（Geolocation） | スマホのGPSなどで今いる場所を調べる |
| ルールを守る | Supabase のトリガーと RLS | 1日3つ、100m以上3km以内、範囲、自分の点だけ、を画面を通さなくても守る |
| プライバシー | トリガーと RLS | 位置を約100mに丸めて保存。打っている途中の点はほかの人に見せない |

陣地（三角形）はデータベースには保存せず、点から毎回計算しています。
三角形を作られた順に並べ、後から作られた三角形と重なる部分を削ってから塗っています。

```
index.html           ゲームの画面
```

## Supabase の設定

くらしの便利帳と同じプロジェクトを使っても、新しいプロジェクトを作っても大丈夫です。
（無料プランはプロジェクトが2つまでなので、同じプロジェクトを使うのがおすすめです）

### 1. 匿名ログインをオンにする

「Authentication」→「Sign In / Providers」（または「Providers」）→「Allow anonymous sign-ins」をオンにして保存します。

同じプロジェクトでくらしの便利帳も動いている場合：匿名でログインした人は「ログインした人」になりますが、便利帳では管理者（admins）に登録された人しか管理の操作ができないので、安全は変わりません。

### 2. テーブルとルールを作る

1. 「SQL Editor」を開き、`supabase/setup.sql` の中身を全部貼り付けて「Run」を押す
2. 注意の画面（Potential issue detected）が出たら「Run query」を押す（作り直し用の drop と revoke が入っているため。データは消えません）
3. 「Table Editor」に `profiles` と `points` ができていれば成功

このSQLで作るもの：

| 作るもの | 内容 |
| --- | --- |
| profiles テーブル | プレイヤーの色とニックネーム。新しい人がログインすると自動で1行できる |
| points テーブル | 打った点（緯度・経度・日付・時刻） |
| 自動でプレイヤーを作る仕組み | ログインした人に、12色から順番に色を割り当てる |
| 点を打つときのルール（トリガー） | 1日3つまで、同じ日の点は100m以上3km以内、薩摩川内市のまわりだけ。位置は小数第3位（約100m）に丸めて保存 |
| RLS | 自分の点は全部見られる。ほかの人の点は、三角形ができた日の分だけ見られる。点を打つ・取り消す・名前を変えるのは自分の分だけ |
| GRANT | ログインしていない人は何もできない。書きこめる列を lat・lng・nickname に限る |

### 3. config.js に書く

```js
window.APP_CONFIG = {
  SUPABASE_URL: "https://xxxx.supabase.co",
  SUPABASE_KEY: "公開用の鍵（Publishable key か anon public）"
};
```

くらしの便利帳と同じプロジェクトなら、便利帳の `config.js` と同じ内容で大丈夫です。
service_role（secret）の鍵は、ぜったいに書かないでください。

### 4. 公開する

新しいリポジトリ（Public）に中身をすべてアップロードし、「Settings」→「Pages」で `main` と `/(root)` を選んで「Save」します。

## 公開したあとの確認

- [ ] 開くと、左上に「プレイヤー○」と自分の色が出る
- [ ] Supabase の「Authentication」→「Users」に、メールアドレスのないユーザーが1人増えている
- [ ] スマホで「今いる場所に打つ」を押すと、位置情報の許可を聞かれる。許可すると「ここに1つ目を打つ？」と出る
- [ ] その場でもう一度押すと「近すぎます」と出る。100m以上歩くと打てる
- [ ] 3つ目で三角形が塗られる。4つ目は「今日はもう3つ打ちました」と出て打てない
- [ ] 別のプレイヤー（シークレットウインドウ）からは、打っている途中の点が見えない
- [ ] シークレットウインドウ（プライベートブラウズ）で開くと、別の色のプレイヤーになる
- [ ] 別のプレイヤーで、最初の三角形に重なるように三角形を作ると、重なったところが後の人の色になる

**1人で重なりを試すには**：ふだんのブラウザとシークレットウインドウ（または別のブラウザ）を使うと、2人のプレイヤーとして遊べます。匿名ログインは「ブラウザごとの番号札」なので、ブラウザを変えると別人になります。歩きながら、2つのブラウザで交互に打つと、重なりを試せます。

**パソコンで試すとき**：パソコンは位置の誤差が大きく、打てないことが多いです。Chrome の開発者ツール（F12）→ 右上の︙ →「More tools」→「Sensors」で「Location」を選ぶと、好きな場所にいることにして試せます（授業で仕組みを見せるときにも使えます）。

## ルールを変えるとき

ルールは2か所に書いてあります。両方を同じ数にしてください。

| ルール | setup.sql | index.html |
| --- | --- | --- |
| 1日の点の数 | `game_rule` の `points_per_day` | `RULE.perDay` |
| 点どうしの距離（最大） | `game_rule` の `max_distance_m` | `RULE.maxDistanceM` |
| 点どうしの距離（最小） | `game_rule` の `min_distance_m` | `RULE.minDistanceM` |
| 位置の誤差の上限 | （なし） | `RULE.maxAccuracyM` |
| 位置を丸めるけた数 | `game_rule` の `round_digits` | （画面の round3） |
| 打てる範囲 | `game_rule` の `min_lat` など | （画面にはなし） |

setup.sql を書きかえたら、もう一度 SQL Editor で実行します。データは消えません。
※ 1日の点の数を3以外にすると、三角形ではなくなるので、画面の計算（buildTriangles）も直す必要があります。

## データを消すとき（やり直したいとき）

SQL Editor で次を実行すると、すべての点が消えます（プレイヤーは残ります）。

```sql
delete from public.points;
```

匿名のプレイヤーを消したいときは、「Authentication」→「Users」で選んで削除します（そのプレイヤーの点も一緒に消えます）。

## 注意

- **点は本当に行った場所の記録になります。** 位置は約100mに丸め、打っている途中の点はほかの人に見せないようにしていますが、三角形ができるとその日行った場所がおおまかにわかります。家の近くでは打たないように、授業で最初に伝えます
- 現在地はスマホから送られた値を信じています。開発者ツールなどで位置をごまかすことはできてしまうので、練習や遊び用として使います
- 位置情報は https のページでしか使えません（GitHub Pages は https なので大丈夫です）
- 匿名ログインは、ブラウザを変えたり閲覧データを消したりすると、別のプレイヤーになります（前の陣地は引き継げません）
- 新しいブラウザで開くたびにプレイヤーが増えるので、ずるをしようと思えば点を多く打てます。本格的に遊ぶときは、メールや Google のログインに切り替えます
- 打てる範囲は、薩摩川内市（甑島をふくむ）をおおまかに囲んだ四角形です。となりの町も少し入ります
- 地図の右下の「© OpenStreetMap contributors」は、消さずに残す決まりです
